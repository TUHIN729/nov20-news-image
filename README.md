One Day, One World — a hero-led newspaper front page summing up Friday 20 November 2026: the ICJ's historic ruling that Myanmar committed genocide against the Rohingya, the Trump-Xi-Putin peace pact in Shenzhen, the tanker hit near Oman as the Hormuz crisis deepens, Cyclone Akvan slamming India's east coast, the Dow sinking below 50,000, the COP31 draft dropping the fossil-fuel exit, and Israel's buffer zones. Drawn from scratch in TypeScript with Node's standard library only — a 5x7 bitmap font, a small vector rasteriser and a hand-rolled PNG encoder — the program writes entry.png deterministically, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
